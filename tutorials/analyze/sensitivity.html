Sensitivity Analysis

Measure what each layer costs when it is compressed on its own

analyze_sensitivity compresses one layer at a time, evaluates the model with a metric you provide, restores the layer, and moves on. It reports one Δ per layer: the metric lost by compressing that layer alone.

import torch
from fastai.vision.all import *
from copy import deepcopy
from torchvision.models import resnet18, ResNet18_Weights

from fasterai.analyze.sensitivity import analyze_sensitivity, SensitivityAnalyzer
from fasterai.core.all import large_final
from fasterai.sparse.all import Sparsifier
from fasterai.prune.all import Pruner

1. A model and a metric

A ResNet-18 fine-tuned on the cats-vs-dogs split of PETS, at 64 px. It is wrapped in a plain Learner rather than in vision_learner for two reasons that matter on this page: the module names stay the torchvision ones (layer2.0.conv1 rather than 0.5.0.conv1), and the model is the one Pruner is exercised on elsewhere in the docs.

path = untar_data(URLs.PETS)
files = get_image_files(path/"images")

def label_func(f): return f[0].isupper()

dls = ImageDataLoaders.from_name_func(path, files, label_func, item_tfms=Resize(64))

model = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)
model.fc = nn.Linear(512, 2)

learn = Learner(dls, model, metrics=accuracy)
learn.fit_one_cycle(3, 1e-3)
epoch train_loss valid_loss accuracy time
0 0.376383 0.578953 0.754398 00:03
1 0.226512 0.201047 0.912720 00:03
2 0.109474 0.192538 0.926928 00:03

The metric is the accuracy on the validation set. The images are decoded once into tensors, because analyze_sensitivity runs one full evaluation per layer.

valid = [(xb.as_subclass(torch.Tensor), yb) for xb, yb in dls.valid]
n_valid = sum(len(yb) for _, yb in valid)

def accuracy_of(m):
    "Top-1 accuracy of `m` over the validation set"
    m.eval()
    with torch.no_grad():
        correct = sum((m(xb).argmax(1) == yb).sum().item() for xb, yb in valid)
    return correct / n_valid

def wilson(k, n, z=1.96):
    "k out of n and its Wilson 95% interval, as a printable string"
    p, d = k / n, 1 + z**2 / n
    c, h = (p + z**2 / (2 * n)) / d, z * ((p * (1 - p) / n + z**2 / (4 * n**2))**0.5) / d
    return f'{k}/{n} = {100 * p:.2f}% [{100 * (c - h):.2f}, {100 * (c + h):.2f}]'

trained = deepcopy(learn.model).eval()   # pristine copy; each section below starts from it
base = accuracy_of(trained)
print('baseline  ', wilson(round(base * n_valid), n_valid), '- single run')
baseline   1370/1478 = 92.69% [91.25, 93.91] - single run

sample is the input the analyzer traces the model with. It has to be a plain torch.Tensor: a fastai TensorImage intercepts the tracing and the dependency graph comes out wrong.

sample = valid[0][0][:1].clone()
print(type(sample).__name__, tuple(sample.shape))
Tensor (1, 3, 64, 64)

2. Sensitivity to sparsity

Each layer in turn has 80% of its weights zeroed, is evaluated, and is restored. Every ratio in fasterai is a fraction in [0, 1], hence level=0.8; the level is a choice, not a property of the method, and section 8 runs the same analysis at 0.5, 0.7 and 0.9.

higher_is_better=True tells the analyzer that a drop in the metric marks a sensitive layer, so Δ is baseline - compressed.

result = analyze_sensitivity(
    deepcopy(trained), sample, accuracy_of,
    compression="sparsity",
    level=0.8,
    higher_is_better=True,
    metric_name="accuracy",
)

4. Turning Δ into per-layer sparsity

to_layer_targets maps the measured Δ to one sparsity per layer, weighted by parameter count so that the mean over the model lands on target. gamma controls how far apart the layers are pushed.

targets = result.to_layer_targets(trained, target=0.5, min_ratio=0.1, max_ratio=0.8, gamma=1.5)

for name, ratio in list(targets.items())[:6]:
    print(f'{name:24s} {ratio:7.2%}')

The dict goes straight into Sparsifier.sparsify_model.

model_s = deepcopy(trained)
sparsifier = Sparsifier(model_s, granularity='weight', context='local', criteria=large_final)

The report ends on 50.00% overall — the target that was asked for, computed over the 11,166,912 Conv2d parameters the sparsifier touches, not over the model’s 11,177,538 — and spreads from 9.98% on conv1 to 51.47% on layer4.1. The model scores 1374/1478 after the sparsification against 1370/1478 before; the two intervals overlap, so this single run does not resolve a difference in either direction. Nothing was fine-tuned afterwards, and this page does not compare this allocation with a uniform 0.5.

5. Sensitivity to structural pruning

With compression="pruning", each layer is pruned on a fresh copy of the model with the per-layer target {name: level} — the operation Pruner performs.

analyzer = SensitivityAnalyzer(
    deepcopy(trained), sample, accuracy_of,
    criteria=large_final,
    higher_is_better=True,
    metric_name="accuracy",
)
pruning_result = analyzer.analyze("pruning", level=0.3, verbose=False)
pruning_result.summary()

     4. layer2.1.conv1                 Δ=+0.0453  [group 5]
     5. layer2.0.conv1                 Δ=+0.0379  [group 3]

  🟢 Most Robust (compressible):
     1. layer4.0.conv1                 Δ=0.0000  [group 9]
     2. layer3.1.conv1                 Δ=+0.0014  [group 8]
     3. layer1.1.conv1                 Δ=+0.0020  [group 2]
     4. layer4.0.conv2                 Δ=+0.0020  [group 10]
     5. layer4.0.downsample.0          Δ=+0.0020  [group 10]

  ⚪ Not prunable in isolation (1):
     1. fc                             (group None)

conv1, layer1.0.conv2 and layer1.1.conv2 share one Δ and the tag [group 0]: the residual connections make them write into the same channels, so they are pruned together and one prune produced one Δ for the three of them.

fc is listed apart, as not prunable in isolation — Pruner protects the output layer, so pruning it alone changes nothing. A no-op is not evidence of robustness, so the layer is kept out of both rankings.

7. Sensitivity to quantization

Here level is a number of bits. The weights of one layer at a time are fake-quantized, per output channel.

for bits in (8, 4):
    q = SensitivityAnalyzer(deepcopy(trained), sample, accuracy_of, criteria=large_final,
                            metric_name="accuracy").analyze("quantization", level=bits,
                                                            quant_per_channel=True, verbose=False)
    print(f'{bits}-bit weights, baseline {100 * q.baseline_metric:.2f}% — three largest drops:')
    for layer in q.top(3):
        print(f'   {layer.name:24s} Δ={100 * layer.delta:+.2f} points')
8-bit weights, baseline 92.69% — three largest drops:
   layer1.1.conv1           Δ=+0.14 points
   layer2.0.conv1           Δ=+0.07 points
   layer2.0.downsample.0    Δ=+0.07 points
4-bit weights, baseline 92.69% — three largest drops:
   conv1                    Δ=+3.72 points
   layer2.0.conv1           Δ=+1.69 points
   layer1.0.conv2           Δ=+0.47 points

At 8 bits per output channel the largest single-layer drop is 0.14 points, two images. At 4 bits conv1 costs 3.72 points, layer2.0.conv1 1.69, and every other layer stays under half a point.

8. Several levels at once

sweep re-runs the analysis at each level and returns one result per level.

sweep_analyzer = SensitivityAnalyzer(deepcopy(trained), sample, accuracy_of,
                                    criteria=large_final, metric_name="accuracy")

for r in sweep_analyzer.sweep("sparsity", levels=[0.5, 0.7, 0.9], verbose=False):
    worst = r.top(1)[0]
    print(f'{r.compression_level:>6.0%} sparsity: largest single-layer drop '
          f'{100 * worst.delta:5.2f} points ({worst.name})')

Summary

Call What it gives you
analyze_sensitivity(model, sample, eval_fn, compression=, level=) one Δ per layer, computed with your own metric
higher_is_better= the direction of the metric; with True, Δ = baseline − compressed
metric_name= the name printed in the logs and on the plot
result.summary() the fragile end, the robust end, and the layers that could not be pruned
result.top(n, most_sensitive=) the same two lists, as LayerSensitivity objects
result.plot() Δ per layer as a bar chart
result.to_layer_targets(model, target=, min_ratio=, max_ratio=, gamma=) a {layer: fraction} dict whose parameter-weighted mean is target
result.to_dataframe() every field, including group_id and prunable
SensitivityAnalyzer(...).analyze(compression, level) the same analysis, reusing one analyzer
analyzer.sweep(compression, levels) one result per level

compression is "sparsity", "pruning" or "quantization"; level is a fraction in [0, 1] for the first two and a bit width for the third.

Every number on this page comes from a single run: a ResNet-18 fine-tuned for three epochs on the PETS cats-vs-dogs split at 64 px and scored on its 1478 validation images, one seed, one split. No latency was measured and nothing was fine-tuned after compression.
